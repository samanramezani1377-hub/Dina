# پرداخت و خروجی داده

## پرداخت SaaS
پرداخت SaaS اکنون یک مرز مستقل دارد: تلاش پرداخت با Idempotency-Key در PostgreSQL ثبت می‌شود و رویداد Webhook با کلید provider/event_id دقیقاً یک بار پذیرفته می‌شود. اتصال درگاه واقعی باید در یک adapter پیاده شود و قبل از ارسال event، امضای callback همان درگاه را بررسی کند. هیچ secret در Git نگهداری نمی‌شود.

## خروجی
خروجی CSV با UTF-8 BOM برای Excel و نرم‌افزارهای فارسی ارائه شده است:
- تراز آزمایشی
- دفتر کل
- فروش
- خرید
- موجودی
تمام خروجی‌ها tenant-scoped و برای نقش حسابداری و بالاتر هستند.
